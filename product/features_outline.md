Internship applications tracker
Target audience: Undergraduate students (US) looking for summer internships

Page 1: Home Page
Pressing: Banners like “Today is the last day to apply for XYZ. Hurry up”
Button= Log updates to your applications -> will take you to Applications tracker page
Overview, stats (how many jobs did you apply to this week etc)


Page 2: Applications tracker

![Applications Log Page Screenshot] (applications_tracker_page.png)

Features:
Would prioritize the applications based on deadline (upcoming) or rolling deadline (and show these higher)
Also maybe a column for which CV was submitted, openable as a file in the CV Manager

Page 3: CV Manager

![CV Manager Page Screenshot] (cv_manager_page.png)

Folder with different versions of CV
Ability to import/add/drag and drop CV
Ability to edit CV & save changes as this file, or as a new file
Each file would have a label: Sent to: <list of job applications that the CV was sent to> -> linking back to the applications page
Ability to export in PDF with a custom version that wouldn’t save as the file name on drive (for example, I have a general SWE CV, and I’m applying to LinkedIn to a job titled “Backend Engineer” - I want to submit the same file but with a “CV_<name>_Backend_Engineer” title.

Page 4: Your Friends

“Add a friend” feature - by username and or email address
Notifications: which invites you got
When sending friends request: what do you want shared with your friends (general stats like how many jobs applied to this week or whole dashboard of which jobs are you applying to)
If they add you back, they would appear in the Friends section, and based on what they decided to share, you would either see general stats, or you could click on the stats and see their job board inside, with the following columns: name, link, status, deadline; but without Notes and CV
